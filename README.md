# Barón & Baroncito — Landing

Alquiler de trajes de etiqueta en Rosario · Sarmiento 1311.

## Publicar con GitHub Pages
1. Subí todo el contenido de esta carpeta a la raíz del repositorio.
2. En el repo: **Settings → Pages → Build and deployment → Deploy from a branch**, elegí `main` y carpeta `/ (root)`.
3. En unos minutos el sitio queda en `https://<usuario>.github.io/<repo>/`.

Para usar el dominio propio (`www.baronybaroncito.com`), agregalo en **Settings → Pages → Custom domain** y apuntá el DNS según la guía de GitHub.

## Estructura
- `index.html` — la página.
- `support.js`, `image-slot.js` — scripts que necesita la página (no borrar).
- `assets/` — logo, favicon e imágenes propias.

Las fotos de Unsplash se cargan desde internet; reemplazalas por fotos propias en `assets/fotos/` cuando estén disponibles.
